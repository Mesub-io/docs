# src/docs/skills.mdx

Document the skills kit from @https://github.com/Mesub-io/skills (README:
Skills, Install, What an install copies; catalog.yaml for the skills and
their status; AGENTS.md: One kit, every agent, A skill works alone, Content
rules; each skill's SKILL.md for when it is used and its rules).
What a skill is and why it helps, installing and updating with the commands
run once in an empty project, the skills as a table with the guide each one
follows, a few example requests, what the skills never do, the skills next to
the MCP server, the source and where to report a problem. No agent product
named. The mesub-mcp skill is the one that acts on a live project, not on code.
