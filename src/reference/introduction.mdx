`@mesub/node` wraps this API. Use it directly from any other language.

## Base URL

```bash
curl "https://api.mesub.io/v1/project" \
  -H "Authorization: Bearer $MESUB_API_KEY"
```

Every route lives under `https://api.mesub.io/v1` and takes the project's
**API key** as a bearer token. The key identifies the project: there is no
project id in any path. [Authentication](./authentication.mdx) has the detail.

## Conventions

- Fields are in **snake case**.
- Dates are ISO 8601 strings in UTC.
- Token amounts are **strings** in the token's smallest unit: `"9990000"` is
  9.99 of a token with six decimals.
- Statuses and reasons are lowercase. Mesub may add one later: keep a default
  branch.
- A field the route does not know is refused with a 400, not ignored.
- Every error has [the same body](./errors.mdx), with a `code` to branch on.

## Try a request

Each route's page has a **Try it** button. It opens a panel where you paste an
API key, fill the parameters and send the request from your browser.

Calls are real: they act on the project the key belongs to. The key stays in
your browser and goes only to the API.

The whole API is also described in one
[OpenAPI file](https://docs.mesub.io/openapi.json), which these pages are
drawn from.

## Pagination

Lists take `limit` (1 to 100, 20 by default) and `starting_after`, the id of
the last item of the previous page, and answer `{ data, has_more }`. Items come
newest first.

```bash
curl -G "https://api.mesub.io/v1/subscriptions" \
  -H "Authorization: Bearer $MESUB_API_KEY" \
  -d external_id=user_42 \
  -d limit=50 \
  -d starting_after=cmg1x0abc0001
```

With the SDK, `subscriptions.listAll` and `subscriptions.allAttempts` walk
every page for you.
