<Endpoint id="submitSubscription">

Relays what the wallet signed: the transaction and the terms. Mesub checks both signatures, co-signs, sends the transaction and waits for the chain, so this call is slow by design: up to 90 seconds.

Safe to send again unchanged. Mesub recognises what it already co-signed and answers from the chain, so a customer is never charged twice.

</Endpoint>
