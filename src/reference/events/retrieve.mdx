<RequestExample>

```bash title="cURL" lines=false
curl "https://api.mesub.io/v1/events/evt_cmg1x0evt0001" \
  -H "Authorization: Bearer $MESUB_API_KEY"
```
```js title="fetch" lines=false
const response = await fetch('https://api.mesub.io/v1/events/evt_cmg1x0evt0001', {
    headers: {
        Authorization: `Bearer ${process.env.MESUB_API_KEY}`,
    },
});

if (!response.ok) {
    const { code, retryable } = await response.json();
    // branch on `code`
}
const data = await response.json();
```
