import { Mesub } from '@mesub/node';

const mesub = new Mesub(); // reads MESUB_API_KEY

<Endpoint id="checkAccess">

Whether a customer may use a plan, and what explains the answer. Always 200 for a customer, subscribed or not: a customer who never subscribed answers `access: false` with `status: "none"`. The 404 is about the slug, never about them.

<More>

Leave `plan` out to get every plan of the project the customer has anything on.

</More>
